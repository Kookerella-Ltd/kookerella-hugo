CsExcel is a C# wrapper around [FsExcel](https://github.com/misterspeedy/FsExcel) — an F# library for
writing Excel workbooks via ClosedXML — that lets you build spreadsheets from a flat, declarative list
of instructions rather than ClosedXML's cell-by-cell object model.

## Install

```
dotnet add package CsExcel
```

## Dependencies

Targets .NET Standard 2.0. Depends on FsExcel, FSharp.Core, and ClosedXML.
